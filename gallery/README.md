# Wajha community gallery

Templates shared by the community. The app lists them in the template
picker (served from this folder by jsDelivr) and installs them for offline use.

```
index.json                 generated by `npm run gallery:index`: what the app downloads
.hashes.json               generated: template file hashes, so versions bump on change
templates/<id>/
  template.json            the template (pretty-printed JSON)
  preview.jpg              generated: first three slides, 1200 x 860
  assets/<sha256>.png      images the design uses, if any
```

To add a template: design it in Wajha, *Save as template*, export the
`.wajha-template` file, copy its `template.json` (and `assets/`) into
`templates/<id>/`, then:

```sh
WAJHA_GALLERY=1 WAJHA_GALLERY_ONLY=<id> npx vitest run scripts/gallery-previews.test.ts
npm run gallery:index
npx vitest run scripts/gallery.test.ts
```

The full guide, the template format and the pull request checklist are in
[docs/TEMPLATES.md](../docs/TEMPLATES.md#5-contributing-to-the-community-gallery).
